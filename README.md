## 🎬 חוויית המסע הקולנועי (The GSAP Scroll Journey)

דף הנחיתה בנוי כ**מסע חווייתי מתמשך** (12 פרקים מסונכרנים), המשתמש בטכנולוגיות הגלילה המתקדמות ביותר:

1. **פרק 00 // שער הפתיחה הקולנועי (Hero Expanding Portal)**:  
   תמונת השער נפתחת ומתרחבת בהדרגה (`ScrollTrigger Scrub`) מרוחב גלויה לרוחב מסך מלא (`100vw × 100vh`), בעוד הטקסט הפותח נסוג ומגלה את שער הכניסה למסע.
2. **פרק 01 // החזון והסטנדרט (The Warm Standard)**:  
   שורות מפתח הנדלקות בקצב הגלילה ומציגות את עמודי התווך של ההפקה.
3. **פרק 02 // ארכיטקטורת החלל (Pinned Horizontal Space Walkthrough)**:  
   נעילת מסך וגלישת פנורמה אופקית (Parallax), המפרטת את שלושת מתחמי האירוע:
   * **מתחם 01**: קבלת פנים ומפגש ראשוני (19:00 - 20:15, גווני אמבר 2700K, עד 68dB, קוקטייל אישי).
   * **מתחם 02**: טקס החופה ומוקד המעמד (20:30 - 21:00, תאורה רכה לצילום, סאונד היקפי צלול, נגישות מלאה).
   * **מתחם 03**: סעודת אבירים ורחבת ריקודים (21:00 ועד אחרון האורחים, הפרדה אקוסטית, מנות שף מתוזמנות).  
   *📱 מותאם למובייל באמצעות סרגל טאבים סגמנטי קומפקטי ללא עומס.*
4. **פרק 03 // שקט נפשי וביטחון (Trust & Guarantees)**:  
   כרטיסי זרקור רדיאליים (`SpotlightCard`) המציגים התחייבות לתקציב סגור ומעטפת ניהולית מלאה.
5. **פרק 04 // סוגי אירועים בתפירה אישית (Event Specializations)**:  
   חתונות יוקרה, אירועי חברה וגאלה, בר/בת מצווה אקסקלוסיביים ומסיבות VIP.
6. **פרק 05 // מתכנן קונספט אישי (Interactive Concept Planner)**:  
   מחשבון אינטראקטיבי לבחירת סוג אירוע, כמות אורחים, סגנון ומרכיבי הפקה, המייצר סיכום מפרט מלא.
7. **פרק 06 // חשיפת מסך קולינרית (Curtain Wipe & Sensory Reveal)**:  
   מסיכת גזירה (`Clip-Path Inset`) שנפתחת עם גלגלת העכבר וחושפת את הקולינריה והמיקסולוגיה.
8. **פרק 07 // גלריית אירועים נבחרת (Gallery & Lightbox)**:  
   סינון לפי קטגוריות ותצוגת הגדלה (Lightbox) של רגעי שיא.
9. **פרק 08 // מתודולוגיית עבודה (4-Step Production Process)**:  
   אפיון, תכנון מפורט, ירידה לפרטים, וניהול בשטח ביום האירוע.
10. **פרק 09 // רגעים ועדויות (Testimonials & Social Proof)**:  
    חוות דעת של זוגות ומנהלי שיווק.
11. **פרק 10 // שאלות נפוצות (FAQ Accordion)**:  
    מענה ברור ושקוף לשאלות המפתח.
12. **פרק 11 // יצירת קשר ישירה ומאובטחת ב-WhatsApp**:

## 🔒 אבטחת פרטיות והגנה מפני סורקי רשת (Anti-Scraping Protection)

באתר הוטמע מנגנון הגנת פרטיות קפדני:
* **אפס חשיפת מספר טלפון גלוי:** כל מספרי הטלפון הגלויים וקישורי ה-`tel:` הוסרו לחלוטין מהקוד, מה-HTML וממטא-דאטה, על מנת למנוע מבוטים, סורקי רשת (Scrapers) ורשימות תפוצה לאסוף את מספר הטלפון.
* **קידוד והרכבה דינמית (Runtime Obfuscation):** יעד הפנייה ב-WhatsApp מורכב דינמית בזמן ריצה בזיכרון הדפדפן, ללא מחרוזות טקסט גלויות של מספרי טלפון בקובצי המקור.
* **הודעות מוכנות מראש (Pre-filled Contextual Messages):**
  * לחיצה על **"תיאום פגישה"** פותחת ישירות הודעה מנוסחת לשיחת היכרות מול נופר.
  * שימוש ב**"מתכנן הקונספט"** שולח את כל המפרט שהוגדר (אורחים, סגנון, מרכיבים) ישירות ל-WhatsApp.
  * לחיצה על סוג אירוע בגלריה מעבירה את שם האירוע והפרטים הרלוונטיים.

## 🛠️ טכנולוגיות וארכיטקטורה (Tech Stack)

* **Framework:** React 19 (TypeScript)
* **Build Tool:** Vite 6
* **Styling:** Tailwind CSS v4 + PostCSS
* **Animation & Motion:** GSAP 3.15 + ScrollTrigger (Pinned scrubbing, Parallax, Clip-path wipes)
* **Smooth Scrolling Engine:** Lenis Momentum Smooth Scroll (60fps / 120fps fluid interpolation synced with GSAP ticker)
* **Typography & Fonts:** הגדרת פונטים מקומיים עם `font-display: swap` ומערך Fallback אפס-השהיה (`Assistant`, `Cormorant Garamond`, `Cinzel`)
* **Hardware Acceleration:** אנימציות מקומיות במאגר מבוססות GPU (`transform3d`, `will-change`) למניעת Layout Thrashing
* **Icons:** Lucide React
* **Micro-Interactions & UI:** React Bits (SpotlightCard, ShinyText, CountUp, StarBorder, Particles)
* **SEO & GEO:** Schema.org JSON-LD Structured Data, OpenGraph, Web Vitals Optimization (LCP < 1.2s, Zero CLS).
